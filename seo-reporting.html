Velonie Weekly SEO Report

A private SEO reporting application that monitors Google Search performance and delivers structured weekly insights.

Velonie Weekly SEO Report helps monitor organic search visibility, keyword performance, website impressions, search clicks, click-through rates, and average search positions through Google Search Console.

Operated by Velonie Automation for internal reporting. Read-only Search Console access, authorized through Google OAuth.

What the application does

  • Google Search performance monitoringTracks how the website performs in Google Search week to week.
  • Keyword performance analysisShows which search queries bring visibility and clicks.
  • Landing page visibilityShows which pages appear in search and how often.
  • Search click and impression trackingReports clicks and impressions for the reporting period.
  • CTR and average position monitoringFollows click-through rate and average ranking position over time.
  • Country and device analysisBreaks performance down by country and by device type.
  • Weekly performance comparisonsCompares the latest week with the previous period.
  • Automated email reportingSends the finished report to the authorized recipient.

How it works

  1. 1

    Step 1: Google Search Console

    Google Search Console provides authorized search performance data through read-only access.

  2. 2

    Step 2: Google Apps Script

    Google Apps Script processes the reporting information and builds the weekly comparison.

  3. 3

    Step 3: Gmail delivery

    Gmail delivers the weekly SEO report to the authorized recipient.

Data and privacy

  • The application uses Google OAuth. The account owner grants access through Google's consent screen, and the application never receives a Google password.
  • Search Console access is read-only.
  • Search Console data is used only for SEO reporting.
  • Reports are delivered only to the authorized email recipient.
  • The application does not modify website content or Search Console settings.
  • Access can be revoked at any time through Google Account Connections.
