System architecture

The Facebook auto-poster pipeline

A content rotation system that generates, brands, and publishes posts with zero manual steps — built because the client had no consistent posting cadence and no bandwidth to create one manually.

Content

Rotation without repetition

Google Sheets drives the content calendar so the client can add or reorder posts without touching the workflow itself.

Generation

On-brand images, generated per post

OpenAI generates the base image per post; a custom FastAPI microservice on Render overlays branding before it ever reaches Facebook.

Publishing

Fully automated, no manual posting

Final asset is pushed live via the Facebook Graph API — the client's team never opens Meta Business Suite for routine posts.

Problem-solving in the field

Debugging the Page-to-Page DM restriction

Meta restricts Page-to-Page direct messaging by default, which broke part of the intended engagement flow once the client's Page was connected to GHL's Social Planner.

Instead of routing around it with a workaround that would've broken on Meta's next policy update, the connection was diagnosed at the permissions level, confirming exactly which Meta-side restriction was active before adjusting the integration to work within it — not against it.
