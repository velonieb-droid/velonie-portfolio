Prompt quality checklist

    How to use the builder

    1. Pick a template or start with an empty form.
    2. Fill in the sections. Only the main objective is required, but each extra section usually improves the answer you get.
    3. Watch the checklist to see what is still missing.
    4. Edit the final prompt if you want, then copy it or download it as a text file and paste it into your AI assistant.

    What this tool does and does not do

    The builder takes what you type and arranges it under clear headings: role, objective, context, input, instructions, constraints, tone and output format. That is all it does. It does not generate ideas, rewrite your text or call an AI model, and the same input always produces the same prompt.

    Why structure helps

    • Role points the assistant to the right expertise and vocabulary.
    • Objective states the one result you need, so the answer does not drift.
    • Context gives the audience and situation the assistant cannot guess.
    • Instructions break the work into steps you can check.
    • Constraints set limits such as length, scope and what must not be invented.
    • Output format saves you from reformatting the answer afterwards.

    Example prompt

    # Role
You are an experienced B2B email copywriter.

# Objective
Write a short outreach email that introduces our bookkeeping service to dental clinics.

# Instructions
1. Open with a specific problem the reader recognises
2. End with a single clear call to action

# Constraints
- Maximum 130 words
- No invented statistics

# Output format
A subject line, then the email body in plain text.
