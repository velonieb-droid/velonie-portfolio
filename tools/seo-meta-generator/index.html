          Checking an existing page
          
    
          The page checker reads a page's HTML and reports what it finds: the current title and description and their lengths, the number of H1 headings, whether a canonical link and social tags are present, a noindex instruction, and images with no alt attribute. It then suggests titles and descriptions built from the page's own heading and opening text, and lists the words and two-word phrases the page uses most, giving extra weight to the title and headings.
          
    
            
      
          • It is rule-based, not AI. Suggestions are drafts made from text already on the page. Read and edit them before you use them.
            • 
      
          • Why an address may not work. Browsers stop one website from reading another unless that website allows it, and most do not. When that happens, paste the HTML source or upload the saved page. The result is the same.
            • 
      
          • Privacy. Pasted or uploaded HTML is processed on your device and is not sent anywhere. When you enter an address, your browser requests that page from its own website, as it would if you visited it.
            • 
      
          • Limits. It checks one page at a time, not a whole site, and it reads the HTML source only. Text that a page adds later with JavaScript will not be seen.
            • 
    
          

    
          What each tag does
          
    
          Title tag
          
    
          The title appears in the browser tab and is usually the clickable headline in search results. Put the main topic first and keep it specific to the page. Search engines can rewrite or shorten titles, so treat the length guide as a guide, not a rule.
          
    
          Meta description
          
    
          A short summary that search engines may show under the title. It does not directly affect rankings, but a clear description can help people decide to click.
          
    
          Canonical link
          
    
          Tells search engines which URL is the main version when the same content can be reached at more than one address, for example with and without tracking parameters.
          
    
          Robots meta tag
          
    
          Controls indexing for the page. Pages are indexed and links followed by default, so you only need this tag when you want something different, such as noindex on a thank-you page.
          
    
          Open Graph and Twitter/X cards
          
    
          These control the title, description and image shown when the page is shared on platforms such as Facebook, LinkedIn, WhatsApp and X. When a share image is provided the tool uses the large image card, otherwise the compact summary card.
          

    
          Example output
          
    
          <title>Emergency Plumber in Austin, TX | Rivera Plumbing</title>
<meta name="description" content="Licensed Austin plumbers for leaks, clogged drains and water heater repair.">
<link rel="canonical" href="https://www.example.com/emergency-plumber-austin/">
          

    
          Good to know
          
    
            
      
          • Special characters such as &, < and quotation marks are converted to HTML entities, so the output stays valid.
            • 
      
          • Correct meta tags help search engines and social platforms understand a page. They do not guarantee higher rankings or a particular appearance in results.
            • 
      
          • Every page on a site should have its own title and description.
