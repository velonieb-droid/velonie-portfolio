What each tag does

    
Title tag

    
The title appears in the browser tab and is usually the clickable headline in search results. Put the main topic first and keep it specific to the page. Search engines can rewrite or shorten titles, so treat the length guide as a guide, not a rule.

    
Meta description

    
A short summary that search engines may show under the title. It does not directly affect rankings, but a clear description can help people decide to click.

    
Canonical link

    
Tells search engines which URL is the main version when the same content can be reached at more than one address, for example with and without tracking parameters.

    
Robots meta tag

    
Controls indexing for the page. Pages are indexed and links followed by default, so you only need this tag when you want something different, such as noindex on a thank-you page.

    
Open Graph and Twitter/X cards

    
These control the title, description and image shown when the page is shared on platforms such as Facebook, LinkedIn, WhatsApp and X. When a share image is provided the tool uses the large image card, otherwise the compact summary card.

Good to know

    
    
      
  • Special characters such as &, < and quotation marks are converted to HTML entities, so the output stays valid.
    • 
      
  • Correct meta tags help search engines and social platforms understand a page. They do not guarantee higher rankings or a particular appearance in results.
    • 
      
  • Every page on a site should have its own title and description.
