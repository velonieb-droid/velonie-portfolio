    What FAQ schema is
    
    
    FAQPage is a Schema.org type that describes a list of questions and their answers in a format machines can read. It is added to a page as JSON-LD inside a <script type="application/ld+json"> element. It does not change how the page looks to visitors.
    

    
    Example output
    
    
    {
  "@context": "https://schema.org",
  "@type": "FAQPage",
  "mainEntity": [
    {
      "@type": "Question",
      "name": "How long does a CRM setup take?",
      "acceptedAnswer": {
        "@type": "Answer",
        "text": "Most small-business CRM setups take one to two weeks."
      }
    }
  ]
}
    

    
    Will this give me rich results in Google?
    
    
    No, and no tool can promise that. Valid structured data does not guarantee any special appearance in search results. Google has also retired the FAQ rich result, so FAQ markup no longer produces the expandable questions that used to appear under a listing. The markup is still valid Schema.org data that describes your content clearly to search engines and other systems that read structured data.
    

    
    Good to know
    
    
      
      
    • Only mark up questions and answers that are visible on the same page.
      • 
      
    • Answers are treated as plain text. Quotation marks, emoji and other Unicode characters are handled for you.
      • 
      
    • The tool writes the < character as <. This is standard JSON, and it means text such as </script> in an answer cannot break the page you paste it into.
      • 
      
    • Rows that are completely empty are ignored. A row with only a question or only an answer must be completed or removed.
